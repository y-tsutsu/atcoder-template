# 苦手分野メモ

解法を知れば理解できるものの、自力では方針に気づきにくい典型を重点的に復習するためのメモ。

## 各要素の寄与で考える

### 寄与で考えることに気づくポイント

- 多数の区間、組、操作などについて、値の総和を求める問題である。
- 一つの区間などの値を、含まれる各要素の足し算へ分解できる。
- 区間を一つずつ固定すると対象が多すぎる、または端点を動かしたときの値の更新が難しい。
- 各要素を固定すると、「その要素を含む対象の選び方」や「その要素に掛かる係数」を数えられそうである。

特に、次のように目的の値が各 `A_i` の一次式で表せるなら、和の順番を入れ替えて寄与を集められないか考える。

```text
答え = Σ_i A_i × (A_i に掛かる係数)
```

区間和の総和なら `A_i` の登場回数、区間平均の総和なら各区間から受け取る `1 / 区間長` の合計が係数になる。

### 寄与を考えるときの手順

1. 注目する要素を `A_i` 一つに決める。
2. ほかのすべての要素を `0` にしたと想像する。
3. `A_i` を含む区間や組などを列挙し、それぞれから答えへ加わる値を書く。
4. 共通する `A_i` をくくり出し、残った係数を求める。
5. すべての `i` について `A_i × 係数` を足す。
6. 係数を毎回求め直さず、隣の要素へ移ったときに増える対象と消える対象の差分を考える。

「寄与」は単なる登場回数とは限らない。対象ごとに重みが違うなら、その重みの合計を求める。

また、「分母を足す」のではなく、`1 / 区間長` という分数を係数として足す。分子の `A_i` は最後に一度だけ掛ける。

最大値、中央値、`(区間和)^2` など、ほかの要素を `0` にした結果を単純に足して元へ戻せないものには、この分解をそのまま適用できない。

### 固定端の走査と寄与を使い分ける

まずは得意な形である、右端や中央を固定した走査を検討する。

- 固定した位置までの情報を、総和、個数、値ごとの頻度、少数のDP状態などでまとめられる。
- 位置を一つ動かしたとき、古い寄与を引いて状態を変更し、新しい寄与を足せる。

この場合は無理に各要素の寄与へ変換せず、固定端の走査でよい。

- ABC177 C：右端を固定し、左側の値の総和を持つ。
- ABC318 E：中央を固定し、値ごとの左の個数と右の個数の積の総和を差分更新する。
- ABC365 E：右端を固定し、そこで終わる区間のXORをビットごとの `0/1` の個数に集約する。

一方、区間を伸ばすたびに過去の各区間の重みが個別に変化し、少数の状態へまとめにくい場合は、各要素の寄与へ視点を変える。

ABC468 Eでは、右端を伸ばすと既存の全区間の分母が区間長ごとに変わる。そこで区間を固定する代わりに各 `A_i` を固定し、`A_i` を含む全区間から受け取る係数を集める。

### 重複する寄与には代表を決める

一つの対象を複数の要素が数えそうなら、どの要素に担当させるかを一意に決める。

代表の候補には、区間内における次の位置などがある。

- 最初または最後の出現
- 最小値または最大値を取る位置
- 条件を満たす最も左または右の位置

ABC371 Eでは、区間内に同じ値が複数回あっても種類数への寄与は1回だけである。その値の最初の出現位置を代表にすると、現在位置を `i`、直前の同じ値の位置を `prev` として、

```text
L の選択肢：prev+1 ... i
R の選択肢：i ... N
寄与する区間数：(i-prev)(N-i+1)
```

と重複なく数えられる。

### 二重和の独立な軸を分離する

二重ループの中身が `i` だけに依存する部分と `j` だけに依存する部分の積なら、分配法則で分離できる。

```text
Σ_i Σ_j f(i)g(j) = (Σ_i f(i))(Σ_j g(j))
```

ABC058 Dでは、長方形の横幅と縦幅を独立に選べる。横幅の総和と縦幅の総和を別々に求め、最後に掛ければよい。

### 寄与を数えやすい単位を選ぶ

寄与の単位は配列の要素とは限らない。

- 値の種類や出現位置
- ビット
- 隣り合う座標間の隙間
- 条件を満たす組や状態

ABC058 Dでは、隣り合う座標間の隙間を固定する。その隙間をまたぐ左端と右端の選び方を数えることで、隙間の長さが横幅または縦幅へ何回使われるかを求められる。

### 境界だけの特別扱いは無理に消さない

番兵は配列の端などの境界条件を統一するために便利だが、問題固有の除外条件までは消してくれない。

ABC365 Eでは長さ1の区間を答えに含めないため、次のどちらかの処理が必要になる。

- 長さ1の状態を答えへ加える前に除外する。
- 一度すべて加えた後、長さ1の区間の寄与をまとめて引く。

短く明確に書けるなら、初項や境界を特別扱いしても問題ない。

### 現時点で苦手な寄与問題

単純な整数係数の寄与や、固定端を動かしながら状態を差分更新する問題は解ける。

特に注意して練習するのは、全区間について次の性質を持つ問題である。

- 区間ごとに一つの要素が受け持つ重みが変わる。
- 左端と右端の選択肢を単純な積に分離できない。
- 固定端を動かすと過去の多数の状態がそれぞれ異なる変化をする。

この場合は、各要素を固定して係数を集める、注目位置を一つ動かした係数の差を取る、重複しない代表を決める、といった視点を優先して試す。

### 例題：ABC468 E - Sum of Average

すべての非空区間 `[L, R]` の平均の総和を求める。

区間 `[L, R]` に含まれる `A_i` の寄与は、

```text
A_i / (R - L + 1)
```

である。したがって、`A_i` に掛かる係数を `C_i` とすると、

```text
C_i = Σ_{L=1}^{i} Σ_{R=i}^{N} 1 / (R - L + 1)
答え = Σ_i A_i × C_i
```

となる。

調和数を、

```text
H_k = 1 + 1/2 + ... + 1/k
```

とする。最初の要素を含む区間は `[1, 1], [1, 2], ..., [1, N]` なので、

```text
C_1 = H_N
```

である。

注目する要素を `i` から `i+1` へ移すと、両方を含む区間の寄与は変わらない。変化するのは次の区間だけである。

- 新しく増える区間：`L = i+1`、長さは `1, 2, ..., N-i` なので `H_{N-i}` を足す。
- 消える区間：`R = i`、長さは `1, 2, ..., i` なので `H_i` を引く。

よって、

```text
C_{i+1} = C_i + H_{N-i} - H_i
```

で全係数を左から更新できる。

`1, 1/2, ..., 1/N` の累積和を前計算すれば各調和数を `O(1)` で取得でき、全体を `O(N)` で計算できる。mod上の割り算には逆元を使う。

## 離散区間の境界条件

### 重なりと隣接を区別する

整数やマスを表す閉区間では、二つの区間が同じ点を共有しなくても、端が1だけ違えば隙間なくつながる。

左の区間を `[L_1, R_1]`、右の区間を `[L_2, R_2]` とすると、条件は次のように異なる。

```text
重なる：      L_2 <= R_1
隣接も許す：  L_2 <= R_1 + 1
1マス空く：   L_2 == R_1 + 2
```

閉区間 `[L, R]` を半開区間 `[L, R+1)` へ変換した場合、隣接を含めて結合できる条件は `L_2 <= E_1` になる。

### 気づくためのチェックポイント

- 対象が実数直線ではなく、整数、マス、日、時刻などの離散的なものである。
- 問題文が「区間が重なる」ではなく、「すべて覆う」「隙間がない」「連続している」と要求している。
- 区間の端を含む閉区間と、Pythonで扱いやすい半開区間がコード内で混在している。
- `<=` と `<`、または `+1` の有無だけで判定している箇所がある。

提出前に、少なくとも次の4ケースを手で確認する。

```text
重なる：      [1,3], [2,4]
端を共有：    [1,2], [2,4]
隣接のみ：    [1,1], [2,4]
1マス空く：   [1,1], [3,4]
```

### 例題：ABC457 E - Crossing Table Cloth

左端が `S` の布の右端を `u`、右端が `T` の布の左端を `v` とする。

2枚の布が重なる必要はなく、整数のマス `[S,T]` を隙間なく覆えればよい。したがって判定条件は、

```text
v <= u + 1
```

となる。`v <= u`では、`[S,u]`と`[u+1,T]`のように隣接するだけの正しい組を除外してしまう。
